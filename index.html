책 4장의 첫 예제 (LangChain, 요약)
@tool
def multiply(x: float, y: float) -> float:
    """Multiply 'x' times 'y'."""
    return x * y

llm_with_tools = llm.bind_tools([multiply, add])
ai_msg = llm_with_tools.invoke("What is 393 * 12.25?")
ai_msg.tool_calls
# [{'name': 'multiply', 'args': {'x': 393, 'y': 12.25}}]

핵심

모델은 실행하지 않음. 도구 이름과 인자를 담은 요청만 생성. 실행·검증·실패 처리는 그 요청을 받는 코드의 몫.
